# Pocket Plan

A modern cross-platform personal finance application built with Flutter.

Pocket Plan is designed to help users track their income and expenses, organize transactions by category, and understand their monthly spending habits through a simple and intuitive mobile experience.

> 🚧 **Project Status:** Currently under active development.

## Planned Features

* Track income and expenses
* Categorize transactions
* View monthly balance and spending summaries
* Filter transactions by category and date
* Local data persistence
* Monthly spending charts
* Light and dark theme support
* Responsive UI for Android and iOS

## Tech Stack

* **Flutter**
* **Dart**
* **Riverpod** — State management *(planned)*
* **Local Database** — Data persistence *(planned)*
* **REST API integration** *(planned)*
* **Git & GitHub** — Version control
